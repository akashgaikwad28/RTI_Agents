# Admin Dashboard

The RTI Agent backend is complemented by a comprehensive React based dashboard designed for System Administrators, Approvers, and System Engineers.

## Core Features

### 1. Human In The Loop (HITL) Queue
Some RTI queries are highly sensitive and require human verification before a final response is generated.
- **Review Queue**: Displays pending drafts generated by the Consensus Agent.
- **Diff Viewer**: See exactly what the AI changed versus the source RAG context.
- **Approval Flow**: Approve, reject, or edit responses before final transmission.

### 2. Live Agent Tracing
Built on top of LangSmith APIs, the dashboard allows administrators to watch agents in real time.
- View active graphs.
- Inspect the scratchpad of the Planner Agent.
- Watch the Debate Agent's internal dialogue as it evaluates arguments.

### 3. RAG Index Management
Administrators can control the knowledge base directly.
- **Upload Documents**: Upload new PDFs or Word documents.
- **Trigger Scrapers**: Manually initiate a scraping run on target government URLs.
- **View Chunks**: Inspect how a specific document was chunked and embedded to debug retrieval quality.

### 4. Cost and API Usage
Track token usage across different models.
- **Cost Analytics**: View cost per query, cost per agent, and aggregate monthly usage.
- **Model Fallbacks**: Toggle primary LLM providers (e.g., from OpenAI GPT 4o to Anthropic Claude 3.5 Sonnet) dynamically without redeploying code.
