# Skills Showcase

This repository serves as a comprehensive portfolio demonstrating expertise across multiple domains of modern software engineering.

## 1. AI Engineering & Agentic Systems
- **LangGraph Orchestration**: Designed cyclical, multi actor graphs with reflection loops.
- **Debate Architecture**: Implemented multi agent debate to resolve conflicting context and minimize hallucinations.
- **RAG Systems**: Built robust retrieval pipelines using FAISS, Qdrant, and Cross Encoder reranking.
- **LLM as a Judge**: Developed automated evaluation pipelines using RAGAS for continuous quality monitoring.

## 2. Backend & Platform Engineering
- **FastAPI**: Developed high performance, asynchronous REST APIs.
- **Observability**: Integrated structured logging, Prometheus metrics, and LangSmith distributed tracing.
- **State Management**: Implemented checkpointing for LangGraph using PostgreSQL, enabling Human in the Loop workflows.

## 3. Full Stack Development
- **Next.js App Router**: Built this documentation and dashboard using React 19, TailwindCSS 4, and RSC (React Server Components).
- **Fumadocs**: Deployed an enterprise grade technical documentation portal.
- **Security**: Designed RBAC middlewares and JWT based authentication flows.

## 4. Systems Architecture
- **Microservices**: Containerized all services using multi stage Docker builds.
- **CI/CD**: Configured GitHub Actions for testing, evaluation, and deployment.
- **Resilience**: Engineered fault tolerant vector retrieval with exponential backoffs and graceful degradation.
